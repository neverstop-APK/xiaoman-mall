# deploy/：部署配置

**一句话**：本地开发完全用不到；要把网站放到服务器上时，从这里挑一种方案。

## 装了什么
- `Dockerfile`：可选的生产镜像。只复制运行时代码，预置商品/分类数据，用非 root 用户启动，健康检查打 `/api/health`，数据放 `/app/data` 卷。构建命令在文件头注释里。
- `docker-compose.yml`：单服务 Compose。只监听 `127.0.0.1:3000`，数据放命名卷，容器根文件系统只读、去掉全部 capability，适合配合宿主机 Nginx。
- `nginx-小满商城.conf`：Nginx 站点配置。80 跳 443、TLS、反向代理、SSE 关闭缓冲、静态资源缓存、gzip、安全响应头、1 MB 请求体上限。
- `xiaoman-mall.env.example`：生产环境变量模板，复制到 `/etc/xiaoman-mall.env` 后改端口、数据目录、模型 Key 等。
- `xiaoman-mall.service`：systemd 托管单元。非 root 运行、开机自启、崩溃拉起、日志进 journald，并用 ProtectSystem 等选项收紧权限。

## 和谁配合
`docs/部署-服务器与域名.md` 是这五个文件的操作手册：先买域名、配 DNS，再装 Node 或 Docker，然后用这里的文件起服务，最后申请证书、验证 HTTPS 和备份。

## 注意
- 部署文件不参与 `npm start`，本地演示不用管它们。
- `.env` 里可能有模型 API Key，不要提交真实值；仓库里只放 `.example`。
- 上 HTTPS 后 Cookie 才会带 Secure；如果前面有反向代理，确认 `X-Forwarded-Proto` 传对了。
- 数据是 JSON 文件，迁移服务器时记得一起备份 `XM_DATA_DIR`。
