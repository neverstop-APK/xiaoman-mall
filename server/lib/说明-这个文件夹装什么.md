# server/lib/：通用工具

**一句话**：和“商品、购物车、订单”无关的底层工具，换个项目也能直接用。

## 装了什么
- `response-统一响应格式.js`：`ok()` / `fail()` 统一 `{ code, message, data }` 信封；`HttpError` 把“状态码 + 业务码 + 中文原因”打包成一个异常。
- `store-JSON数据存储.js`：7 张表的表名到文件名映射、内存缓存、读写；Windows 上遇到 EBUSY 会短暂退避重试；支持 `XM_DATA_DIR` 换数据目录。
- `static-静态文件服务.js`：返回 `public/` 下的 HTML/CSS/JS/SVG，处理默认页、404 页、MIME、304 缓存和目录穿越防御。
- `session-会话与Cookie.js`：解析 `Cookie` 请求头、读取当前用户、写/清 `xm_session`；Cookie 带 HttpOnly、SameSite=Lax，HTTPS 下自动加 Secure。

## 和谁配合
`routes/` 用 response，`services/` 用 store，`index-服务入口.js` 用 static，`router-迷你路由.js` 用 session 把用户放进 `ctx.user`。

## 读法
先看 response（最短），再看 store（数据怎么落地），最后看 static 和 session（HTTP 的两端）。

## 注意
这一层不认识“商品”“订单”这些词；一旦发现业务判断写进来了，就说明放错层了。
