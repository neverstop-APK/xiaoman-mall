# server/lib/：通用工具

**一句话**：和“商品、购物车、订单”无关的底层工具，换个项目也能直接用。

## 装了什么
- `response-统一响应格式.js`：`ok()` / `fail()` 统一 `{ code, message, data }` 信封；`HttpError` 把“状态码 + 业务码 + 中文原因”打包成一个异常。
- `store-JSON数据存储.js`：读写 JSON、内存缓存、表名到文件名的映射（`products` → `products-商品数据.json`）。
- `static-静态文件服务.js`：返回 `public/` 下的 HTML/CSS/JS/SVG，处理 404 页、MIME、304 缓存和目录穿越防御。

## 和谁配合
`routes/` 用 response，`services/` 用 store，`index-服务入口.js` 用 static。

## 读法
先看 response（最短），再看 store，最后看 static。
