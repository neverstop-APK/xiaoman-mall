# server/data/：JSON 数据表

**一句话**：这个项目的“数据库”，四张表就是四个 JSON 文件。

## 装了什么
- `products-商品数据.json`：26 件商品，含 id、名称、品牌、分类、价格、库存、销量、标签、封面等字段。
- `categories-商品分类.json`：6 个分类（数码、家居、文具、户外、服饰、配件）。
- `carts-购物车数据.json`：运行时生成，存每辆购物车，第一次加购时自动创建。
- `orders-订单数据.json`：运行时生成，存每一笔订单。

## 注意
- 商品和分类是随项目提供的固定数据；购物车和订单是运行时数据，已写进 `.gitignore`。
- 服务运行时会缓存到内存，直接手改文件不会被读到；改完要重启服务。
- 想得到干净的演示环境，把 carts / orders 两个文件内容改成 `[]`，再重启即可。
