# server/routes/：HTTP 接口层

**一句话**：最薄的一层，只做“取参数 → 调 service → 按统一格式返回”。

## 装了什么
- `products-商品接口.js`：列表、详情、相关推荐、分类、首页推荐，共 5 个 GET。
- `cart-购物车接口.js`：查购物车、加购、改数量、删单项、清空，共 5 个。
- `orders-订单接口.js`：创建、按用户查列表、查单笔、支付、取消，共 5 个；`requireUser`（第 20 行）和 `assertAccess`（第 26 行）保证只能看自己的订单。
- `auth-认证接口.js`：注册、登录、退出、`/me`，共 4 个；登录成功写 HttpOnly Cookie。
- `agent-购物助手接口.js`：对话（SSE 流式，第 22 行）、确认下单（第 73 行）、取会话、取配置、取工具清单，共 5 个。

## 和谁配合
每个文件导出一个注册函数，`index-服务入口.js` 启动时调用它，把路径注册进 `router-迷你路由.js`；真正的规则在 `../services/`。

## 注意
这里不写金额、库存、筛选规则，也不拼 SQL / 文件路径。路由一薄，业务就能被接口、脚本、AI 工具和测试共用。
