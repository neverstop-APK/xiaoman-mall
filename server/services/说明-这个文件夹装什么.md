# server/services/：业务规则层

**一句话**：这个项目“算错了会出事”的逻辑都在这里，和 HTTP 无关。

## 装了什么
- `catalog-商品查询服务.js`：关键词、分类、价格、排序、分页、分类计数、首页推荐、相关商品。
- `cart-购物车服务.js`：创建/查找购物车、加购累加、改数量、删除、清空、算单项小计与总金额、校验库存。
- `orders-订单服务.js`：重算金额与运费（满 99 免运，否则 12 元）、生成订单号、扣库存、加销量、清空购物车、支付/取消与状态校验。

## 和谁配合
被 `routes/` 调用；只依赖 `lib/` 和 `data/`，不碰 `req` / `res`。

## 读法
先看 catalog 的 `query()`，再看 cart 的 `addItem()`，最后看 orders 的 `create()`。
