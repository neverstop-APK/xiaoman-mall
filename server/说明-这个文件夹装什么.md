# server/：后端代码

**一句话**：只在 Node 里运行的服务端代码，浏览器下载不到这里的任何文件。

## 装了什么
- `index-服务入口.js`：启动 HTTP 服务；`/api` 开头交给路由，其余交给静态文件。
- `router-迷你路由.js`：注册路径、匹配 `:id`、解析 query 与请求体、统一错误处理。
- `data/`：JSON 数据表（商品、分类、购物车、订单）。
- `lib/`：响应格式、JSON 存储、静态文件三个通用工具。
- `services/`：商品、购物车、订单的业务规则。
- `routes/`：HTTP 参数层，把请求转给 services。

## 和谁配合
`public/` 里的页面用 fetch 请求 `/api/...`，请求最终在这里被处理，结果再返回给浏览器渲染。

## 读法
从 `index-服务入口.js` 往下读：一个请求进来 → 路由 → 接口 → 服务 → 数据。
