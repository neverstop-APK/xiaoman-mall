# server/：后端代码

**一句话**：只在 Node 里运行的服务端代码，浏览器下载不到这里的任何文件。

## 装了什么
- `index-服务入口.js`：创建 HTTP 服务（第 37 行）、健康检查 `/api/health`（第 61 行）、把 `/api` 交给路由（第 78 行）、其余交给静态文件；启动时打印地址，端口被占用时给中文提示。
- `router-迷你路由.js`：`add()` 注册“方法 + 路径”，`handle()` 匹配 `:id`、解析 query 与 body、捕获 `HttpError` 转成 JSON；第 116–125 行把 Cookie 解析出的当前用户放进 `ctx.user`。
- `agent/`：AI 购物助手的编排、工具、规则引擎、大模型适配器、会话存储。
- `data/`：7 张 JSON 表（商品、分类、购物车、订单、用户、会话、助手会话）+ 调用日志。
- `lib/`：统一响应、JSON 存储、静态文件、Cookie 与登录态四个通用工具。
- `services/`：商品查询、购物车、订单、用户认证四组业务规则。
- `routes/`：商品、购物车、订单、认证、助手五组接口，一共 24 个。

## 和谁配合
`public/` 里的页面用 fetch 请求 `/api/...`，请求在这里被路由分给接口，再调服务层读写 JSON；结果按 `{ code, message, data }` 返回，前端拿到 `data` 后渲染。

## 读法
从 `index-服务入口.js` 往下：一个请求进来 → 路由 → 接口 → 服务 → 数据。读通一条商品列表后，再读购物车和订单，最后读 `agent/`。

## 注意
所有相对路径都以 `server/` 为基准；服务启动后会把数据读进内存，直接改 JSON 不会立刻生效，要重启。
