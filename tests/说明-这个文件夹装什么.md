# tests/：自动测试与 AI 评测

**一句话**：不靠手点，用命令验证“改完有没有把别的地方弄坏”。

## 装了什么
- `unit/`：4 个单元测试文件，共 37 条。直接调 service，不启动服务，覆盖商品查询、购物车、订单、认证的核心规则。
- `api/api-接口集成.test.mjs`：9 条集成测试。启动真实后端进程（端口 3210、临时数据目录），用 fetch 走完整 HTTP 链路，覆盖 Cookie、401/403、下单、助手 local 模式。
- `eval/`：AI 助手的 30 条评测用例、评测执行器、最近一次结果。
- `测试辅助-临时数据目录.mjs`：创建/清理临时 `XM_DATA_DIR`，让测试不碰演示数据。

## 怎么跑
- `npm test`：单元 + 接口，共 46 条。
- `npm run test:unit` / `npm run test:api`：只跑其中一类。
- `npm run test:eval`：跑 30 条 AI 评测，会重写 `tests/eval/评测结果.json` 和 `docs/AI评测报告.md`。

## 和谁配合
测试直接 require `server/services/` 或启动 `server/index-服务入口.js`；评测复用真实接口与助手，不改业务代码。

## 注意
测试使用独立端口和临时目录，失败不会污染 `server/data`；不要在测试里连生产数据。
