# tests/api/：接口集成测试

**一句话**：启动一个真的后端进程，用真的 HTTP 请求验证整条链路。

## 装了什么
- `api-接口集成.test.mjs`：9 条用例。启动 `server/index-服务入口.js`，端口 3210，`XM_DATA_DIR` 指向临时目录，`AGENT_MODE=local`。

## 覆盖什么
- 商品列表、关键词搜索、分类与价格筛选。
- 购物车加购、改数量、删除。
- 下单、支付、取消，以及金额由服务端重算。
- 注册、登录、Cookie 往返、未登录 401、访问他人订单 403。
- AI 助手 local 模式的搜索与确认下单。

## 和谁配合
测试结束会 SIGTERM 服务进程（Windows 上必要时 taskkill），再删临时目录；端口和文件都释放，可重复跑。

## 注意
它测的是“进程能不能启动、Cookie 能不能来回、SSE 能不能按事件吐”，所以不要改成直接调路由函数，那样会漏掉启动和会话的坑。
