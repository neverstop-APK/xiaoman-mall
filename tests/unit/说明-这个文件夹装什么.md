# tests/unit/：单元测试

**一句话**：只测 service 的输入输出，不启动 HTTP 服务，跑得最快。

## 装了什么
- `catalog-商品查询服务.test.mjs`（9 条）：关键词、分类、价格区间、排序、分页、非法参数。
- `cart-购物车服务.test.mjs`（10 条）：创建、加购累加、改数量、删除、清空、库存上限、售罄。
- `orders-订单服务.test.mjs`（9 条）：金额与运费重算、库存扣减、支付、取消、重复操作。
- `auth-用户认证服务.test.mjs`（9 条）：注册校验、密码不落明文、登录、token、退出、重复用户名。

## 和谁配合
每个文件用 `node:test` + `assert/strict`，通过 `XM_DATA_DIR` 指向临时目录，只复制商品/分类种子数据。

## 读法
挑一个你熟悉的 service，先看测试名，再看它怎么造数据、怎么断言；写新功能时照着加一条。

## 注意
单元测试不验证页面和路由；接口层的行为在 `tests/api/`。
