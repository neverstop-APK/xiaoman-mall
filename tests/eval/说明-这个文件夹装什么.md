# tests/eval/：AI 助手评测

**一句话**：用 30 条固定用例，量一量助手选工具、填参数、完成任务、少胡说八道的能力。

## 装了什么
- `评测用例-ai助手.json`：30 条用例，覆盖考核 9.1–9.7：对话、searchProducts、多轮“便宜一点”、写操作确认、多步预算规划、歧义澄清、超范围拒答、提示词注入、流式与会话。
- `run-评测.mjs`：执行器。启动隔离服务（端口 3211、`tests/eval/.tmpdata`），逐条发 HTTP/SSE 请求，解析 meta/status/delta/products/cart/action 等事件，统计工具选择、参数、完成率、幻觉率、澄清/拒答正确率。
- `评测结果.json`：最近一次运行的逐条结果与汇总，供对比不同模型。

## 怎么跑
- `npm run test:eval`：默认用本地规则引擎，不需要网络和 Key。
- 配好模型环境变量后再跑一次，就能得到“本地 vs 大模型”的对比数据。
- 结果会同时写入 `docs/AI评测报告.md`。

## 注意
- 评测不修改业务代码，也不为了让用例通过而放宽断言；发现产品缺陷应写进报告。
- `.tmpdata/` 是运行产物，已被 gitignore，不要提交。
- 断言看的是“工具名 + 参数 + 最终动作”，不是模型说了多少漂亮话。
