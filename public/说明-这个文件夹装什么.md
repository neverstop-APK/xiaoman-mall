# public/：前端页面与资源

**一句话**：浏览器真正下载和执行的代码都在这里，`static-静态文件服务.js` 把整个目录映射成网站根目录。

## 装了什么
- 五个页面：`index-首页.html`、`products-全部商品页.html`、`product-商品详情页.html`、`orders-我的订单页.html`、`404-页面不存在.html`。
- `partials/`：页脚、购物车抽屉、结算弹窗，只写一份，由服务端 include。
- `css/`：8 个样式文件。五个基础层按“基础 → 布局 → 组件 → 页面 → 补充”加载，`auth`、`agent`、`catalog` 是三个功能层。
- `js/`：14 个 ES Module。五个基础设施（api、ui、store、auth、card）、四个组件（购物车抽屉、结算、登录弹窗、AI 面板）、五个页面入口（首页、全部商品、详情、订单、404）。
- `assets/products/`：26 张商品封面 SVG。

## 和谁配合
页面本身只有骨架和空容器；打开后由 `js/` 里的入口文件请求 `/api/...`，拿到数据再填进 DOM。顶部账号按钮和右下角助手面板也由 JS 注入，除 404 外的四个页面共用同一套。购物车、结算、页脚来自 `partials/`，改一次五个页面同时生效。

## 注意
- 直接双击 HTML 文件打不开完整功能：ES Module 和接口都需要通过 `http://127.0.0.1:3000` 访问。
- 页面里没有内联脚本，是为了配合服务端的 CSP；新增交互请写进 `js/` 模块。
- 改样式先判断属于哪一层，不要把所有页面样式都塞进 `pages`。
