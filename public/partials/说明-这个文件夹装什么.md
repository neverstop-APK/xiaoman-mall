# public/partials/：公共 HTML 片段

**一句话**：页脚、购物车抽屉、结算弹窗只写一份，由服务端在返回页面前拼进去。

## 装了什么
- `footer-公共页脚.html`：五个页面共用的页脚导航。
- `cartdrawer-公共购物车.html`：侧拉购物车，含商品行、数量步进、运费进度、合计、清空、去结算。
- `checkout-公共结算弹窗.html`：收货人、手机号、地址、备注和金额确认。

## 怎么用
页面里写一行标记，不要直接复制片段内容：

```html
<!-- include: cartdrawer -->
```

服务端 `server/lib/partials-公共片段.js` 会把它替换成对应文件。片段文件名只允许在 `FILES` 里登记过的三个，页面不能借这个机制读任意路径。

## 注意
- 片段里不要再写 include，渲染只做一层，避免递归。
- 片段是 HTML 壳，不带业务逻辑；事件绑定仍然在 `public/js/` 里。
- 404 页只引页脚，不引购物车和结算弹窗，因为它没有加载对应的脚本。
