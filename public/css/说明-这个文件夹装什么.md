# public/css/：样式表

**一句话**：按“基础 → 布局 → 组件 → 页面 → 补充 → 功能层”分层，后加载的可以覆盖前面的。

## 装了什么
- `base-设计变量与基础样式.css`：颜色/字号/间距变量、reset、按钮、输入框、价格等基础类。
- `layout-导航与页面布局.css`：容器、吸顶导航、Hero、区块标题、商品网格、页脚、断点。
- `components-通用组件样式.css`：卡片、筛选 chip、分类卡、侧拉抽屉、购物车行、Toast、弹窗、分页、空状态、骨架屏。
- `pages-各页面专属样式.css`：首页 Hero 与推荐、详情两栏、订单页、404。
- `extra-结算与补充样式.css`：结算金额框、加购动画、订单按钮、窄屏补充。
- `auth-登录与账号样式.css`（新增）：顶部账号按钮与用户菜单、登录/注册弹窗、表单错误提示、密码强度提示。
- `agent-购物助手样式.css`（新增）：右下角悬浮按钮、对话面板、消息气泡、工具调用卡片、待确认订单卡、输入区与手机端全屏。

## 和谁配合
四个 HTML 都按同一顺序引入这七个文件；类名和 `js/` 里生成的模板一一对应。

## 注意
- 改颜色先改 base 里的变量；改某个页面再动 pages，不要在多个文件重复写颜色。
- auth 和 agent 依赖 base 的变量与按钮，必须放在最后加载，否则会覆盖不到。
- 新增组件优先放 components；只有“只有一个页面用”的样式才进 pages。
