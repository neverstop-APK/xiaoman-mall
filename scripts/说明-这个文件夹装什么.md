# scripts/：开发脚本

**一句话**：只在开发时手动跑的一次性工具，不参与网站运行。

## 装了什么
- `gen-covers-生成商品封面.js`：读取商品 JSON，按分类配色和商品 emoji 生成 26 张 SVG，写到 `public/assets/products/`，并把 `cover` 路径回写进商品 JSON。

## 怎么跑
在项目根目录执行 `npm run covers`，或 `node scripts/gen-covers-生成商品封面.js`。

## 注意
脚本用商品 id 做随机种子，同一件商品每次生成的图都一样；改了商品名会生成新文件名，旧图需要手动清理。
