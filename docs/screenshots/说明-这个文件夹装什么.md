# docs/screenshots/：界面截图

**一句话**：项目各个关键界面的真实截图，README 和 PDF 里会引用。

## 装了什么
- `home.png`：首页首屏（1440 宽）。
- `catalog.png`（新增）：全部商品页，搜索、分类、价格、排序与分页。
- `catalog-filtered.png`（新增）：目录页叠加分类与价格后的结果。
- `mobile-catalog.png`（新增）：390px 下的目录页。
- `product.png`：商品详情页。
- `cart.png`：侧拉购物车。
- `checkout.png`：结算弹窗。
- `order.png`：订单结果页。
- `auth.png`（新增）：登录 / 注册弹窗与登录后的账号菜单。
- `agent.png`（新增）：AI 购物助手对话与待确认订单卡。
- `mobile-home.png` / `mobile-product.png`：390px 手机端首页与详情页。
