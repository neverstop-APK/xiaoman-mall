# 代码地图：类名、id、data-* 分别指向哪里

> 读任何一个页面卡住时，先来这里按名字查。本文由脚本扫描 `public/` 生成，行号对应当前仓库。

**一句话**：`.css` 只定义名字、`.html` 和 `.js` 产生 DOM、行为挂在 `data-*` 而不是 class 上。

| 统计 | 数量 |
| --- | --- |
| CSS 类名 | 213 |
| 出现在 HTML 里的类名 | 99 |
| 只由 JS 模板生成的类名 | 106 |
| 定义了但当前没用到的类名 | 7 |
| id（HTML 定义 / JS 模板定义） | 88 / 26 |
| `$('#id')` 调用点 | 134 |
| `data-*` 属性 | 20 |

## 0. 三步定位法

1. 搜 `class="名字"` → 命中就是静态 HTML；
2. 没命中，搜带引号的 `'名字'` → 命中就是 JS 模板字符串里拼出来的；
3. 想知道点了做什么，**别搜 class**，搜 `[data-名字]` 或 `$('#id')`。

例：`add-btn` 的完整链路 ——

| 环节 | 位置 | 说明 |
| --- | --- | --- |
| 长什么样 | `components.css:144` | 圆形加号按钮的骨架 |
| 状态样式 | `extra.css:52` | `.add-btn.is-added` 加购后的对勾动画 |
| 谁生成的 | `card.js:61` | 模板字符串，class 是硬编码的 |
| 点了做什么 | `home.js:408`、`product.js:268` | `closest('[data-add]')` 事件委托 |

结论：**class 只解释长相，`data-*` 才解释行为**。

## 1. 文件书写顺序（依赖驱动的 8 轮）

| 轮次 | 写什么 | 为什么排这里 | 写完怎么验证 |
| --- | --- | --- | --- |
| 0 | 设计变量 + 类名约定（纸上） | 变量和命名是后面所有文件的输入 | 能说出 `--color-*` 和 `.前缀-部位` 两条规矩 |
| 1 | `base.css`、`ui.js`、`api.js` | 三者零 import，是全站叶子 | 控制台 import 一下 `$` 能用 |
| 2 | 一个页面的骨架 + `layout.css` | 5 个页面共用一份头尾 | 导航能跳、页面不塌 |
| 3 | `components.css` 定名字 → JS 模板产出这些名字 | 名字先定、生成后置；反了要两头改 | 卡片在页面上有样式 |
| 4 | `store.js` | 只依赖 `api`，是唯一状态源 | 角标和抽屉数字一致 |
| 5 | 四个页面逻辑（组合根） | import 最多，必须最后 | 按 常量 → URL 状态 → render* → load* → bindEvents → init 写 |
| 6 | `cartdrawer` → `checkout` → `auth` → `authui` → `agent` | 依赖逐层加深，agent 最深 | 每加一个跑一遍对应页面 |
| 7 | 后端 `lib → services → routes → router → index` | service 不碰 req/res，可先单测 | `npm test` 的单元部分全绿 |
| 8 | `pages / extra / auth / agent / catalog` 样式收口 | 覆盖前 7 轮，必须最后挂 | 按同样顺序写进 HTML 的 link |
