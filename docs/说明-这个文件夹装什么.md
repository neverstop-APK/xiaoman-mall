# docs/：项目文档

**一句话**：给“人”看的资料，不参与程序运行。

## 装了什么
- `小满商城-文件说明书.pdf`：14 页图文版，逐个解释文件作用、请求链路、知识点。
- `接口文档-前后端约定.md`：14 个接口的参数、响应示例、错误码、排查步骤。
- `演示脚本-答辩怎么讲.md`：8 分钟演示顺序、三条链路讲法、高频追问。
- `screenshots/`：首页、列表、详情、购物车、结算、订单和手机端截图。

## 和谁配合
README 负责“怎么跑、做了什么”，这里负责“细节和怎么讲”；代码改了记得同步接口文档。

## 读法
先看 PDF 的第 1–3 节，再看接口文档，最后用演示脚本走一遍。
