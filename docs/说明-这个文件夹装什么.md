# docs/：项目文档

**一句话**：给“人”看的资料，不参与程序运行。

## 装了什么
- `小满商城-文件说明书.pdf`：19 页图文版，逐个解释文件作用、请求链路、知识点，已包含账号、AI 助手、测试与部署。
- `说明书-小满商城.html`：同一份说明书的网页版，方便在浏览器里搜索。
- `接口文档-前后端约定.md`：24 个接口的参数、响应示例、错误码、排查步骤。
- `阅读路线-从跑起来到讲清楚.md`：按“先跑、再读、最后讲”的顺序排的 11 站（0–10）路线，含账号、AI 助手、测试与部署。
- `演示脚本-答辩怎么讲.md`：8 分钟演示顺序、关键链路讲法、高频追问。
- `AI评测报告.md`：30 条用例的结果，工具选择 40/40、参数 46/46、幻觉 0/27。
- `Prompt-Engineering与AI协作.md`：系统提示词、工具定义、约束与降级策略的说明。
- `部署-服务器与域名.md`：从零部署到 HTTPS、进程守护、备份的完整步骤。
- `screenshots/`：10 张界面截图，含登录与 AI 助手。

## 和谁配合
README 负责“怎么跑、做了什么”，这里负责“细节和怎么讲”；代码改了记得同步接口文档和评测报告。

## 读法
先看 PDF 的第 1–3 节建立全局，再按阅读路线走一遍；准备答辩时用演示脚本，改接口时查接口文档。
